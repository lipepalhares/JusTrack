# JusTrack — Canal de Distribuição

Canal oficial de **download e atualização** do JusTrack — Gestão Jurídica.

Os instaladores (Windows `.exe` e macOS `.dmg`) e o manifesto de atualização
(`latest.json`) são publicados aqui como **Releases**.

- Site: https://justrack.com.br
- O código-fonte é privado. Este repositório contém apenas os arquivos de
  distribuição, acessíveis publicamente para que o aplicativo possa se atualizar.
